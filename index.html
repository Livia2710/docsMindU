Como usar esta página

Cada rota abaixo abre com um clique e mostra a requisição, a resposta e um exemplo de código pronto — uma aba para o site (React) e outra para o app (Android). Use o seletor Local / Web no topo para trocar o endereço em todos os exemplos de uma vez.

Local: http://localhost:8080 — precisa do backend rodando no seu computador (docker compose up).
Web: https://mindu-api.onrender.com — sempre disponível, mas pode levar até 1 minuto para responder na primeira chamada do dia (o serviço "dorme" quando fica sem uso).

Toda rota, exceto as marcadas público, exige o cabeçalho Authorization: Bearer <token>, obtido no login.

Configuração inicial

Um helper único que já resolve a URL e o token. Crie em src/api.js:

const BASE_URL = "http://localhost:8080"; // troque para a URL Web ao publicar

export function getToken() {
  return localStorage.getItem("mindu_token");
}

export async function api(path, { method = "GET", body, isFormData = false } = {}) {
  const headers = {};
  const token = getToken();
  if (token) headers["Authorization"] = `Bearer ${token}`;
  if (!isFormData) headers["Content-Type"] = "application/json";

  const res = await fetch(`${BASE_URL}${path}`, {
    method,
    headers,
    body: isFormData ? body : body ? JSON.stringify(body) : undefined,
  });

  if (!res.ok) {
    const erro = await res.json().catch(() => ({}));
    throw new Error(erro.erro || `Erro ${res.status}`);
  }
  return res.status === 204 ? null : res.json();
}

Adicione ao build.gradle (module: app):

implementation("com.squareup.retrofit2:retrofit:2.11.0")
implementation("com.squareup.retrofit2:converter-gson:2.11.0")
implementation("com.squareup.okhttp3:logging-interceptor:4.12.0")

RetrofitClient.java — monta o cliente e injeta o token salvo:

public class RetrofitClient {
    private static final String BASE_URL = "http://10.0.2.2:8080/"; // emulador -> localhost da máquina
    private static Retrofit retrofit;

    public static Retrofit getInstance(Context context) {
        if (retrofit == null) {
            OkHttpClient client = new OkHttpClient.Builder()
                .addInterceptor(chain -> {
                    SharedPreferences prefs = context.getSharedPreferences("mindu", Context.MODE_PRIVATE);
                    String token = prefs.getString("token", null);
                    Request.Builder b = chain.request().newBuilder();
                    if (token != null) b.addHeader("Authorization", "Bearer " + token);
                    return chain.proceed(b.build());
                })
                .addInterceptor(new HttpLoggingInterceptor().setLevel(HttpLoggingInterceptor.Level.BODY))
                .build();

            retrofit = new Retrofit.Builder()
                .baseUrl(BASE_URL)
                .client(client)
                .addConverterFactory(GsonConverterFactory.create())
                .build();
        }
        return retrofit;
    }
}

No emulador Android, 10.0.2.2 aponta para o localhost do seu PC. Em um celular físico na mesma rede, use o IP local da máquina (ex.: 192.168.x.x) em vez disso — a URL Web funciona igual nos dois casos.
